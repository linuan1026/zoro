# 離線雙語閱讀

V3 新增可選的逐句對照：使用工具列新按鈕匯入完整雙語 JSON。格式與範例見
[逐句對照規格](sentence-alignment.md)。原有 Markdown/TXT、PDF+PDF 與頁碼同步獨立保留。

開啟資料庫中的 PDF，在閱讀工具列按「匯入翻譯」，選擇外部完成的 `.md`
或 `.txt`，即可在左側閱讀原始 PDF、右側閱讀譯文。全程不需要 API Key、
BabelDOC、訂閱或網路連線。再次匯入會新增版本，不會覆蓋既有譯文。
版本選單可以切換譯文或回到單 PDF；原有雙語 PDF 按鈕仍可使用。
刪除譯文前會確認，且不會刪除原始 PDF。

Markdown 支援標題、列表、表格、粗斜體、Unicode、上下標 HTML，以及
KaTeX `$行內公式$` 與 `$$區塊公式$$`。HTML 經過安全清理，公式禁止信任
外部內容。圖片仍停用，以替代文字占位，避免追蹤與任意本機讀取。
合法 HTTP(S) 絕對網址以按鈕顯示，需經原生確認後才用外部瀏覽器開啟。
網址禁止帳密、空白、控制字元、反斜線及其他協定；單純閱讀不會抓取遠端資源。
開啟外部連結是自選操作，需要網路；離線閱讀本身仍不需要。
TXT 保留換行並可選取複製。不支援匯入 HTML 檔。
檔案必須為 UTF-8（可有 BOM）或帶 BOM 的 UTF-16 LE/BE，非空白且不超過 10 MiB。

拖曳中間分隔線調整左右比例；比例會保留。右側可獨立搜尋、切換搜尋結果、
調整字體大小及捲動。深淺主題沿用應用程式設定。

## 頁碼對應

請在 Markdown 獨立一行、程式碼區塊以外放置遞增標記：

```markdown
<!-- zoro-page: 1 -->
# 第一頁
第一頁完整譯文。

<!-- zoro-page: 2 -->
第二頁完整譯文。
```

頁碼為 PDF 從 1 開始的實體頁碼，不是印刷頁碼。同步捲動預設關閉。
有標記時可開啟雙向同步：錨點起始位置直接對應，相鄰已知錨點間做近似插值。
第一個錨點前沒有對應，最後錨點之後以兩欄實際可捲動末端做近似插值。
只有一個錨點時也僅頁首精確，尾段仍是近似；工具列區分精確頁首、近似及無可用對應。
缺少 PDF 頁面或超出範圍的標記無法對應。重複、遞減標記不會建立錨點。
沒有標記時正常獨立閱讀，同步開關停用，介面會明確提示。
即使同步關閉，也能用頁碼選單、目前 PDF 頁譯文按鈕與各段「返回原始 PDF」按鈕跳轉。

## 資料與程式整合

新增 Tauri 指令 `list_offline_translations`、`import_offline_translation`、
`delete_offline_translation`，TypeScript 封裝在 `src/lib/commands.ts`。
資料保存在 `<Zoro 使用者資料目錄>/offline-translations/<論文 UUID>/`，
每份文件是獨立 UUID JSON，含原始 PDF 檔名、匯入檔名、格式、內容與時間。
Windows 預設目錄為 `%USERPROFILE%/.zoro`，尊重既有自訂資料目錄。
不需要資料庫遷移；備份時請包含此資料夾。目前不作為 WebDAV 附件同步。
上次選取版本及欄寬為本機 UI 設定；重新開啟 PDF 會恢復可用的上次譯文。
切換版本時字體大小與同步開關會重設。

沿用 `PdfAnnotationViewer` 的搜尋、縮放、文字選取與註記。
既有 `translationStore` 及 BabelDOC 指令維持原樣。使用原生選檔及選檔視窗
授予的檔案讀取範圍，沒有新增無限制檔案權限。
後端寫入、刪除使用驗證過的 UUID，範圍限定在譯文資料夾。
外觀設定可選「繁體中文」，離線閱讀控制項為繁中，其餘沿用既有中文介面。

## 第二輪可靠性改善與限制

`list_documents` 隔離無法讀取或解析的單份 JSON，不刪除、不覆寫。
警告只記檔名、錯誤分類與行列，不記內容；目錄不存在回空清單，其他目錄或列舉
錯誤正常回報。有效文件仍依來源 PDF 篩選、時間由新到舊排列。

`mapTranslationPosition` 過濾非法、逆序、不可到達的幾何位置並限制兩欄捲動範圍。
`bindTranslationScroll` 阻擋程式捲動回授，清理時取消待處理影格。
ResizeObserver / MutationObserver 在字體、欄寬、視窗、PDF 縮放與延遲頁面變更後重算；
分頁停用或切換譯文會清除監聽器、計時器及 observers。

搜尋標記在安全清理與 KaTeX 後產生 HAST，再交給 React 渲染；TXT 直接產生 React
標記。DOM 操作僅讀取搜尋結果與設定捲動，不再替換文字節點。
支援中文字面搜尋、英文不分大小寫；不涵蓋公式、圖片說明或跨越格式邊界的文字，
搜尋框提示亦有說明。閱讀器以譯文 ID 作為 key，切換版本會重設搜尋。
