# V3 離線逐句雙語對照格式

在 PDF 工具列選「匯入逐句雙語對照檔（.json）」，選取 ChatGPT 產生的完整檔案，
不需手動修改資料庫。完整欄位規格見 `docs/sentence-alignment.md`，完整合成範例見
`docs/examples/sentence-bundle.zoro.json`。不呼叫 BabelDOC 或任何外部 AI API。

## ChatGPT 產生檔案時的要求

頂層為 `schema: "zoro.bilingual.v1"`、完整 `markdown` 字串及 `alignments` 陣列。
每組有唯一 `id`（英數、底線、連字號，1–80 字元），以及 `source`、`target` 陣列。
一對多、多對一、多對多放在同一組；跨頁或跨欄句子拆成多個明確片段。

來源片段為 `{page: 1, text: "英文原句", prefix?: "前文", suffix?: "後文", region?: [x,y,w,h]}`。
page 是從 1 開始的 PDF 實體頁碼。region 是顯示旋轉後實體頁面左上角為原點的
0–1 比例，必須完全位於頁面內；用於限定欄位或圖說等區域，未知時不要猜座標。

目標片段為 `{section: 1, text: "中文可見句子", prefix?: "前文", suffix?: "後文"}`。
section 對應 Markdown 的 `<!-- zoro-page: 1 -->` 分段；前言或無頁碼標記文件使用 null。
text 是實際呈現文字，不含粗體等 Markdown 語法。可跨格式節點；段落與儲存格以空白分隔。
不支援公式內文或圖片替代文字的逐句選取。重複句子需提供足夠上下文，不能只猜第幾次出現。

最多 5,000 組，每側 1–32 片段，句子 1–10,000 字元，上下文最多 1,000 字元。
總匯入檔及轉換後儲存資料皆不超過 10 MiB；UTF-8 或含 BOM 的 UTF-16。
JSON 中的換行、引號及 LaTeX 反斜線要正確跳脫。無法確認的對照請省略，不能捏造原句。
範例是虛構資料，不是實際論文，也不是 GUI 驗收證據。

## 定位與操作

沿用 PDF.js 文字層，只讀 Text 節點與 Range 幾何，不改寫原文 DOM。
支援跨 span、跨行、字形正規化、軟連字號與小寫斷字；保留大小寫與希臘字母區別。
大幅跨欄跳躍會形成阻隔，避免把不相鄰的欄位拼成一句。需要時請提供 region 或拆分片段。
每個選取器必須唯一匹配；重複、有歧義、衝突、掃描 PDF 或文字層順序錯亂時寧可不對應。
沒有 OCR、語意推測或百分比逐句對應。部分特殊排版仍可能無法定位，不能宣稱全 PDF 支援。

滑鼠移入英文或中文即雙向對照；點擊可固定，再點或按「解除固定句子」即可取消。
保留文字選取。柔黃色高亮由 React 控制：中文於安全清理、KaTeX 之後的 HAST 階段產生
span，英文使用不攔截滑鼠的矩形覆蓋層。原始 Markdown 內容不會被修改。
預設不自動捲動，需另勾「自動捲動至對應譯文」；它與頁碼同步開關獨立。
若兩者同時開啟，右側自動捲動仍可能經既有同步機制帶動 PDF，偏好獨立閱讀時關閉其中之一。
縮放、延遲頁面、欄寬變動時重算；快速滑鼠移動以 rAF 合併，分頁停用／版本卸載時清理事件。

## 保存與舊版相容

介面將 JSON 轉成既有 Markdown 記錄，前置內部註解 `<!-- zoro-alignment-v1 BASE64 -->`
存放經 UTF-8 Base64 編碼的對照陣列，後面接原封不動的 Markdown。請勿手動編輯此內部格式。
版本名稱由 .json 改為 .md。載入時重驗證並移除內部標頭；對照損壞則停用對照但保留可讀譯文。
沿用 Rust 的 UUID JSON、原始 PDF 關聯、原子保存與損壞隔離，不改 schema／Tauri 權限。
舊 Markdown／TXT、PDF+PDF、搜尋／註記、頁碼同步、安全連結與圖片封鎖均保留。
